# Intuition
Задача на слияние массивов на месте, без использования третьего буферного массива.

# Approach
Нужно идти с конца, потому что некуда сохранять элементы которые еще не прошли сравнения. Знак nums1[i]>nums2[j] обеспечит слиянию устойчивость. После того как с помощью трех указателей поочередно сравнили все эелементы, нужно проверить не остались ли во втором массиве элементы, если да - то скопировать на оставшиеся места в первый.
(Можно оформить реализацию тернарными операторами, чтобы сократить обьем кода)

# Complexity
- Time complexity:
  O(n)

- Space complexity:
  O(1)

# Code
```java []
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int i = m - 1;
        int j = n - 1;
        int k = nums1.length - 1;

        while (i >= 0 && j >= 0){
            if (nums1[i] >= nums2[j]){
                nums1[k] = nums1[i];
                i--;
            }
            else{
                nums1[k] = nums2[j];
                j--;
            }
            k--;
        }

        while(j >= 0){
            nums1[k] = nums2[j];
            j--;
            k--;
        }
    }
}
```

Сортировка слиянием

Основана на идее "Разделяй и властвуй", а именно:
Рекурсивно делит массив на два, вплоть до пар по одному элементу (они отсортированны по определению) и сливает отсортированные

Сложность по времени:
O(n*log(n))
log2(n) разделений массива надвое, вплоть до массивов по одному элементу
n сравнений каждого элемента на каждом уровне
!Сложносить не зависит от случая - (всегда логарифмическая глубина рекурсии, всегда линейное слияние на каждом уровне)

Сложность по памяти:
O(n)
Выделяется - один вспомогательный массив-буфер длинной в исходный массив, и он используется на каждом уровне
!Для связных списков O(1) - просто переставляются ссылки, поэтому сорт. слиянием - лучший выбор для списков
Сложность по памяти - может быть узким местом этой сортировки, особенно в мобильной приложениях, где память критична

Устойчивость - сортировка устойчива, если не меняет порядок равных элементов
Сортировка слиянием устойчива - при равных мы берем левый элемент (который в первоначальном массиве стоял раньше)

Есть прарллельная вариация сортировки слиянием:
Поскольку половинки сортируются независимо, merge sort легко распараллелить на многоядерных процессорах
Arrays.parallelSort() - реализация в джава

Фактически - алгоритм сортировки сводится к двум задачам:
1. Рекурсивное разделение на подмассивы
2. Слияние 

Слияние:
- В новый массив 
Применяется в классической реализации сортировки
Используется третий результирующий массив-буфер 
- In-place с запасом
Т.к. не предусмотренно буфера для хранения элементов массива с запасом - нужно идти с конца!
Так же три указателя:
1. Последний элемент первого списка
2. Последний второго
3. Последний свободный в первом
Добавляем больший
После основного цикла копируем остаток второго в первый

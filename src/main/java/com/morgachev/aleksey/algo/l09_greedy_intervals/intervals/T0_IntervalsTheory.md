Интервалы

Слияние интервалов
Дан (отсортированный) массив пересекающихся интервалов - вернуть массив непересекающихся

Два интервала [a, b] и [c, d ] пересекаются если:
1. a <= d
2. c <= b
В отсортированных по началу первое условие выполняется автоматически, поэтому проверяется только второе:
!Начало каждого  <= Конца каждого!

Решение:
0. Отсортировать по началу
1. Проход:
    - Первый как текущий
    - !Начало следующего <= Конца текущего!
    - По результатам либо расширяем текущий слиянием либо текущий в ответ и следющий становится текущим
2. В конце последний текущий в ответ

Главная идея: соротировка гарантирует что пересекающиеся интервалы идут подряд

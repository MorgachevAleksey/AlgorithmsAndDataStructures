Дерево - структура данных состоящая из узлов и связей между ними

Бинарное дерево удовлетворяет правилу - у каждого узла не более двух потомков

Совершенноe дерево - все уровни кроме последнего должны быть заполнены полностью

Если дерево не врождено в список -  то рекурсия безопасна: глубина O(log n)

---

DFS (обход в глубину)
Обходы:
- Preorder (прямой) Root-Left-Right
- Inorder (центрированный) Left-Root-Right
- Postorder (обратный) Left-Right-Root
Фактически указывает на порядок рассмотрения текущего узла, относительно потомков

Рекурсивный подход, в идеале писать в две функции:
1. Создает результирующий список узлов, вызываеет вторую для его мутации, возвращает список
2. Получает корень дерева и список, обрабатывает базовый случай, рекурсивно обходит дерево, добавляя узлы в список в нужном порядке
Следу принципам ООП, можно перегрузить второй метод (метод с таким же именем но другой сигнатурой) и инкапсулировать метод модификатором доступа private

Существует так же итеративный подход, явно использующий стэк, иммитируя работу неявного стэка вызовов при работе рекурсии
Стэк работает по принципу LIFO - последний пришел, первый вышел
Итеративная реализация разная для каждого обхода
- Inorder:
Создаем результирующий массив значений узлов, указатель на текущий узел и стэк узлов
Условный цикл реализации остановится когда в стэке не останется узлов и текущий будет null, в этом цикле:
1. Спускаемся вниз по левым потомкам до упора, с помощью цикла
2. Обрабатываем текущий узел, удаляя его из стэка и добавляя его значение в результирующий массив
3. Выбираем текущим правого потомка текущего
По завершении работы основного цикла метода возращаем результирующий массив

Свойства деревьев:
1. Высота 
2. Баланс
3. Симметрия
4. Диаметр

Высота
Вычисление высоты (глубины) дерева - рекурсивный подход:
Классический Postorder (как и во многих задачах на деревья), рекурсивно вызвать функцию-счетчик для потомков, затем к большему значению высоты из двух добавить единицу (обработать текущий узел) и вернуть этот результат

Сбалансированнность
Градации баланса:  
- Вырожденное
Фактический связный список
- Несбалансированное
Произвольное, не попадающее в другие категории
- Сбалансированное
Для каждого узла высоты его левого и правого поддеревьев отличаются не более чем на 1
В общем смысле высота гарантированно ограничена log n
- Идеальное
Заполнены все уровни, кроме, возможно, последнего, но на нем все узлы сдвинуты максимально влево
- Совершенное
Полностью заполненное, вплоть до последнего уровня

Симметрия
Симметричное дерево, дерево в котором - левое и правое поддеревья корня явсляются точным зеркальным отражением друг друга

Диаметр
Длина самого длинного пути между любыми двумя узлами
Не обязательно проходит через корень

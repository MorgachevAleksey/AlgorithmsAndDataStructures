# Бинарный поиск
Это метод поиска в любом пространстве где есть монотонность

Базовая идея: на каждом шаге отбрасывать неподходящую по условию половину списка

!Работает только на отсортированном (монотонном) массиве

Сложность всегда O (log n)

Реализации:
- Итеративная
Фактически реализует два указателя
Середина ищется с защитой от переполнения: left+(right-left)/2
Условие обязательно left <= right, иначе можно пропустить последний элемент (он останется один, его тоже нужно рассмотреть)
O(1) по памяти
- Рекурсивная

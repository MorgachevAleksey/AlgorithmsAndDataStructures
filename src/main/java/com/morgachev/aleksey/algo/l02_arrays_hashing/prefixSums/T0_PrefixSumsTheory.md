# Префиксная сумма

Префиксная сумма - это массив pref где pref[i] хранит сумму первых i элементов исходного массива

Ключевое соглашение:
pref[0] = 0 - это entinel элемент, избавляющий от необходимости обработки левой границы l = 0 - стандартная практика
соответсвенно pref.length = n + 1
очень элегантное заполнение массива: pref[i + 1] = pref[i] + nums[i]

тогда 
Сумма элементов на отрезке от индекса L до индекса R:
sum = pref[r + 1] - pref[l]

Тоесть фактически есть два массива:
1) Массив с транзакциями - с нулевого индекса
2) Массив с префиксной суммой - сдвинут на +1, т.к. первый индекс принудительно = 0
!Обязательно long[] - чтобы избежать переполенения!

Фактически вместо каждый раз поиска по O[n], единожды строится поиск всех последовательных транзакицй между индексами по O[n],
а затем за O[1], берется нужная сумма
Так же выделяется доп память на массив префиксных сумм O[n]
!Можно сделать за O[1] по памяти - если модифицироватьь переданный массив на месте!

Префиксная сумма не работает если:
- Массив не статичен и меняется
- Задача не сводится к сумме на отрезке (например минимум на отрезке)

# Intuition
Задача отсылает к задаче 1991 - найти индекс в массиве, сумма элементов до которого невключительно, равна сумме элементов после которого невключительно.

# Approach
Логика та же:
Создать массив префиксных сумм со сдвигом на один из-за нулевого sentinel-элемента
И проходя по массиву циклом сравнивать суммы до и после текущего - при совпадении значений вернуть индекс, если не найден в цикле вернуть -1.

Так же в виде коментария представлено решение за O(1) по памяти - массив префиксных сумм не строится - вместо него циклом строится сумма всех элементов и в основном цикле обновляется сумма до текущего элемента, сравниваются по той же логике.

# Complexity
- Time complexity:
  O(n) - на построение массива префиксных сумм
+
O(n) - в худшем случае, проход по массиву префиксных сумм до поиска совпадения

- Space complexity:
  O(n) - на массив префиксных сумм
  *O(1) - представлено решение где используются две переменные для хранения префиксных сумм

# Code
```java []
class Solution {
    public int pivotIndex(int[] nums) {
        int n = nums.length;
        int[] pref = new int[n + 1];
        int left_sum, right_sum;
        for (int i = 0; i < n; i++){
            pref[i+1] = pref[i] + nums[i];
        }
        for (int i = 0; i < n; i++){
            left_sum = pref[i];
            right_sum = pref[n] - pref[i+1];
            if (left_sum == right_sum){
                return i;
            }
        }
        return -1;
    }
```

Очень часто паттерн применяется в качестве замены вложенных циклов
для более эффективного прохода по массиву

Часто дает выигрыш по сложности O(n) вместо O(n^2)

Если можно использовать два указателя in-place – почти всегда предпочтительнее

Вариации:
- Встречные
    - Реверс массива
    Противоположные указатели меняют местами элементы с помощью буфферной переменной
    - Проверка палиндрома
    Противоположные указатели поочередно сравнивают элементы на равенество
    Существует усложнение, где можно удалить один элемент - реализуется дополнительная функция простой проверки на палиндром,
    в основной проверки в момент несоответсвия символов, вызывается дополнительная функция, которая проверяет подотрезки сначала без правого, потом без левого элемента,
    возвращается результат дополнительной функции
    - Поиск элементов !в отсортированном! массиве дающие в сумме таргет (2, 3, 4 элемента)
    2 - Два встречных указателя проверяют сумму элементов на таргет
    3 - В цикле перебора первого элемента тройки, ва встречных указателя проверяют сумму элементов на таргет, для правого подотрезка
- В одну сторону быстрый\медленный
- Три указателя

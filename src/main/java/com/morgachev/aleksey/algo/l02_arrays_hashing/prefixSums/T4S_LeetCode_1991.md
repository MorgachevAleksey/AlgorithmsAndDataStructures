# Intuition
В задаче требуется найти индекс того элемента в массиве, суммы элементов до и после которого равны. Напрашиваются префиксные суммы.

!Но можно сделать и за O(1) по памяти - просто заведя две переменные для левой и правой суммы и сравнивая\двигая их в цикле!
(И это все еще прексные суммы - просто онлайн, на лету - без офлайн массива)

# Approach
Сумма левых элементов: сумма элементов до текущего невключительно.
Сумма правых элементов: сумма всего массива - сумма всех элемнтов до текущего в цикле включительно.

В случае если суммы до\после текущего равны - возврат индекса текущего, если текущий не найден до конца массива возврат -1.

# Complexity
- Time complexity:
  O(n) - На построение префиксных сумм
+
O(n) - В худшем случае, на проход массива префиксных сумм

- Space complexity:
  O(n) - На массив префиксных сумм

# Code
```java []
class Solution {
    public int findMiddleIndex(int[] nums) {
        long[] pref = new long[nums.length + 1];
        for (int i = 0; i < nums.length; i++){
            pref[i + 1] = pref[i] + nums[i];
        }
        for (int i = 0; i < nums.length; i++){
            long left_sum = pref[i];
            long right_sum = pref[pref.length - 1] - pref[i + 1];
            if (left_sum == right_sum){
                return i;
            }
        }
        return -1;
    }
}
```

# Intuition
Найти два числа, дающие в сумме таргет в отсортированном массиве. Из-за факта сортировки - можно использовать метод двух указателей, т.к. имеет место инвариант цикла

# Approach
Чтобы найти таргет, достаточно инициализировать два встречных указателя на краях массива, и если сумма элементов под их индексами меньше, то двигать левый (увеличивая сумму) или правый (уменьшая) - т.к. массив монотонно возрастает, а решение существует и одно, мы неизбежно его найдем и вернем.

# Complexity
- Time complexity:
  O(n)

- Space complexity:
  O(1)

# Code
```java []
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        int left = 0;
        int right = numbers.length - 1;

        while (left < right){ //т.к. в условии прописано что индексы должны быть 2 разных, не проверяю условие == когда элемент уже является таргетом
            if (numbers[left] + numbers[right] == target){
                return new int[] {left + 1, right + 1}; //Индексация от одного
            }

            if ((numbers[left] + numbers[right]) < target){
                left++;
            }
            else{
                right--;
            }
        }
        return new int[] {}; //Недостижимо т.к. решение есть и будет возвращено раньше
    }
}
```
